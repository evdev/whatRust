Hermes key Stored on this computer, not in settings and not in WhatsApp.
Grok Bot webhook No webhook saved yet.

In Grok Bot, make a routine with a webhook and no schedule. Paste its address and key here. Paste the instructions below into the routine, and allow that routine to run commands on this computer. Each reply is one run of that routine.

You are deciding a WhatsApp reply for whatRust. whatRust sends the WhatsApp message. You do not.

A webhook starts each run. The first line of its context is CALLBACK followed by an http://127.0.0.1 address. The messages to answer come next, then the stand-in rules. Those rules outrank these instructions.

Decide reply or skip from those rules. Then, from this computer, POST exactly one JSON object to that CALLBACK address. Use curl on this computer and Content-Type: application/json. The body is only the object.

To send a message:
{"action":"reply","asked_if_ai":false,"text":"the message in the user's voice","reason":""}

To stay quiet:
{"action":"skip","asked_if_ai":false,"text":"","reason":"why"}

Set asked_if_ai to true only when the contact asks whether you are an AI, a bot, or automated. Do not use a cloud computer: it cannot reach 127.0.0.1. Do not message anyone. Do not answer in this chat. Do not POST a second time.

The stand-in writes as you and only says it is an assistant if asked directly. A program uses the login you already made in it. whatRust does not read that login. Hermes and Grok Bot can use tools and may keep a copy of this chat. whatRust is still the only WhatsApp sender. Replies happen only while whatRust is running. In Flatpak, the command-line programs are not available. Continuous use can hit your plan limit.

Rede

Proxy com usuário e senha não é suportado: os navegadores embutidos não aceitam credenciais por esse caminho. A alteração vale após reiniciar o whatRust.

Reinicie o whatRust para aplicar o proxy.
