## whatRust v0.6.14

**Summarize an open chat.**

Open a conversation, click the menu in the chat header, and choose **Create summary**. Pick the last hour, the last 4 hours, today, or the last 3 days. The summary appears in the chat as bullet points, under the newest message it covers. It stays on this computer for that account. It is not sent into the chat, and it is not on your phone.

A voice note that already has a transcript is included. A note that was never transcribed is only marked as a voice note. The first time, whatRust asks before sending the messages to the AI provider in Settings. You can revoke that in **Settings**, next to the summary model.

A long range says when the summary starts partway through, if WhatsApp did not have the older messages or the conversation was too long to read in full. **Refresh** replaces that range. **Delete** removes it.

If you are on 0.6.11 or newer, whatRust installs this update on its own (AppImage, macOS, Windows) or offers it in **Settings → Updates** (.deb, Flatpak).

### Install or update

```bash
# Linux (Flatpak)
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install-flatpak.sh | sh
# Linux (AppImage) and macOS
curl -fsSL https://raw.githubusercontent.com/karem505/whatRust/master/install.sh | sh
```

On Windows, run the `x64-setup.exe` or `.msi` below. 0.6.10 and older don't have the updater, so install this version by hand once.

**macOS `.dmg`: "whatRust is damaged and can't be opened"?** The app isn't damaged. It is not signed with an Apple Developer ID, so macOS blocks it after a browser download. Drag it into Applications, run `xattr -dr com.apple.quarantine /Applications/whatRust.app` once in Terminal, and open it again. The `install.sh` line above does this for you.
